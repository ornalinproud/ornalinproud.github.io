## How to update vocabulary
1. Open `kanji_data.tsv` file.
2. Add/remove row that follows the header file (subject, kanji, furigana, meaning, example).
3. Save `kanji_data.tsv` file.
4. Upload `kanji_data.tsv` to this repository.
